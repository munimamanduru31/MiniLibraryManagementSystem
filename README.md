# 📚 Mini Library Management System

A simple Java project for managing library books and students.

## 📌 Features

- Add Books
- Issue Books
- Return Books
- Search Books
- View Available Books
- View Student Details
- Generate Library Report
- Due Date Reminder
- Calculate Fine

## 🛠️ Technologies Used

- Java
- ArrayList
- HashMap
- LocalDate
- Exception Handling
- Scanner

## 🧠 Concepts Used

- Classes and Objects
- Methods
- Collections
- Loops
- Switch Case
- Exception Handling
- Date Handling

## ▶️ How to Run

1. Open the project in Eclipse.
2. Open `Main.java`.
3. Run the program.
4. Select an option from the menu.
5. Enter the required details.
